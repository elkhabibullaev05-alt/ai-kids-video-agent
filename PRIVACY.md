# Privacy Policy — YouTube channel automation tools

These tools are private automation scripts used only by the channel owner to upload and schedule videos on the owner's own YouTube channels (MaxTube, MoneyTube, RobloxTube, FunnyRank, DeepSleep, UFCTube, Dough Bros, Hollowmere Tales).

- The app uses the YouTube Data API only to upload videos, set titles/descriptions/thumbnails, schedule publishing, add videos to playlists and read the owner's channel statistics.
- OAuth tokens are stored only on the owner's own computer and are never shared with anyone.
- No data about other users or viewers is collected, sold or shared.
- The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: the channel owner via the YouTube channel's About page.
